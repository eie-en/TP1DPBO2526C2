1. Flow Code :

   Mulai dari kelas kelasan, di sini saya bikin kayak daftar film dengan atribut Kode (bersifat unik), Judul, Sutradara, Genre, dan Tahun Rilis. Atributnya saya bikin private, sehingga diperlukan setter dan getter untuk memberi dan mendapatkan nilai.
   - Ada prosedur display, fungsinya ya ngeshow seluruh array. Kalau daftarnya kosong, akan ditampilkan pesan "Daftar film kosong."
   - Prosedur search, di sini tuh searchnya ada berdasarkan kode sama judul filmnya. Untuk berdasarkan kode, loopnya bakal berenti di tengah karna sifatnya unik, sedangkan judul film akan terus loop sampai akhir list, karena beberapa film judulnya sama (mungkin remake, judul sama beda cerita, beda sutradara)
   - Add, dimulai dari input kode unik. Kalo belum ada, proceed tambahin atribut yang lain, tapi kalo udah ada bakal muncul error message "Error: Kode film sudah terdaftar!". Kemudian error handling lainnya, tahun rilis harus berbentuk angka/integer
   - Delete, input kode unik film yang dihapus. Habistu search ada apa ngga, kalo ada hapus kalo ngga ya error. Balik ke menu
   - Update, sama mekanismenya kayak delete. Search dulu, kalo ada ya proceed langkah selanjutnya yaitu masukin atribut, kalo gaada ya balik menu. Untuk data yang gamau diupdate, kosongin aja/press enter

   Terus ini main nya, aku kasih data dummy dua biji biar tiap programnya jalan kagak kosong terus (ga pake database sih). Diawal ada menu, dengan pilihan : Show, Search, Add, Delete, dan Update. User diminta memilih salah satu fitur yang tersedia dengan mengetikkan nama fiturnya. Program bentuknya infinite loop, hanya akan terhenti ketika input 'malas'

   udah sih gitu aja

   error handling nya tadi udah di jelasin di atas, kayak mastiin kode ga sama, tahun bentuk integer, kodenya ada atau ngga.
